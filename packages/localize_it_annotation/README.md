Annotations for [localize_it](https://pub.dev/packages/localize_it).
This package does nothing without [localize_it](https://pub.dev/packages/localize_it).

It also holds the runtime helpers:

- `'Hallo {name}'.trWithArgs({'name': username})` for named placeholders
- `'Einladung'.trIn('Anlass')` for a string that needs its own translation in one place

See the [localize_it README](https://pub.dev/packages/localize_it) for details.
